# Análisis de datos de ConnectaTel

## 1. Objetivo del proyecto

Analizar los datos de clientes, uso de los servicios y planes de ConnectaTel para comprender el comportamiento de los usuarios, identificar patrones de consumo y proponer recomendaciones que apoyen la toma de decisiones del negocio.

## 2. Datasets utilizados

El análisis utiliza tres conjuntos de datos:

- **Clientes (`users`):** información demográfica y datos de los clientes.
- **Uso (`usage`):** registros del uso de los servicios.
- **Planes (`plans`):** información sobre los planes ofrecidos por la compañía.

## 3. Etapas del análisis

- Exploración inicial de los conjuntos de datos.
- Identificación y tratamiento de valores faltantes, valores inválidos y fechas fuera del período de estudio.
- Análisis exploratorio de las variables y revisión de valores atípicos.
- Segmentación de clientes por grupos de edad y nivel de uso.
- Elaboración de conclusiones ejecutivas y recomendaciones para el negocio.

## 4. Cómo ejecutar el notebook

1. Acceder al repositorio de GitHub.
2. Abrir el notebook del proyecto.
3. Abrirlo en Google Colab.
4. Cargar los datasets necesarios y verificar que las rutas de acceso coincidan con las utilizadas en el código.
5. Ejecutar las celdas en orden.

## 5. Guía de reproducción

Para reproducir el análisis se requiere el notebook y los tres datasets originales: clientes, uso y planes. Los archivos deben estar disponibles en las ubicaciones indicadas en el código. Se recomienda ejecutar las celdas en orden para realizar la exploración, el tratamiento de datos, el análisis y la segmentación de usuarios.
